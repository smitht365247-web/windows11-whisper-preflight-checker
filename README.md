**Free, 100% offline, zero-install Windows 10/11 PowerShell hardware & Whisper pre-flight checker.** Verifies 64-bit GPU VRAM, system RAM, FFmpeg/Whisper binaries, and recommended model tier before downloading gigabytes of weights - zero Python and zero cloud uploads.

## Quick Start
1. Download the latest verified ZIP from [GitHub Releases](https://github.com/smitht365247-web/windows11-whisper-preflight-checker/releases) or [Gumroad](https://smitht365.gumroad.com/l/inttob).
2. Right-click the `.zip` -> **Properties** -> check **Unblock** -> **Apply / OK**, then extract.
3. Double-click `RUN_PREFLIGHT.bat` to run the read-only preflight audit.

## Windows SmartScreen Unblock Note
Because `.bat` and `.ps1` scripts downloaded from the internet are unsigned, Windows SmartScreen may show *"Windows protected your PC"* on first run:
- **Option A:** Click **More info** -> **Run anyway**.
- **Option B:** Right-click the `.zip` before extracting -> **Properties** -> check **Unblock** -> **Apply / OK** -> extract.
